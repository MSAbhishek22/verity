The problem — answers you cannot check

Ask a question and you get an answer in seconds. What you do not get is any way to check it.

Problem 01

Confidence, with no sources

AI tools answer in a steady, certain voice and give you nothing to check — no link, no page, no way to tell a fact from a guess.

Problem 02

Checking takes longer than asking

To verify one fact you have to redo the whole search yourself. It takes longer than asking did, so most people skip it and move on.

Problem 03

Wrong facts travel

The unchecked answer gets copied into an assignment, a pitch, a report. It reads like truth, so it is treated as truth — errors and all.

The solution — how Verity answers

Three steps, and a gate at the end of them. No step writes a word of its own.

1

Search live

Your question goes to live sources — Tavily web search when a key is set, the free Wikipedia API otherwise. Both run at once, and the better result wins.

2

Quote, don’t invent

The answer is built only from sentences the sources actually contain. There is no model writing claims: if a sentence is not in a source, it is not in the answer.

3

Gate the answer

Before you read it, the answer is scored and stamped. Every claim keeps its citation, so checking a claim is one click — not a fresh search.

The gate. Each answer scores 0 to 100 — keyword coverage, source diversity and claim count — and carries one of four stamps, in plain sight:

Grounded Partial Thin No evidence

A weak answer is not dressed up as a strong one. It is labelled, and you decide what to do with it.

GROUNDED 0/100 grounded
