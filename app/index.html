How it works

1 · Search live

Tavily web search when a key is set; the free Wikipedia API otherwise. Both run in parallel and the best result wins.

2 · Quote, don't invent

Extractive synthesis: the answer is built only from retrieved sentences. No LLM, no generated claims.

3 · Gate the answer

Every claim keeps its citation. The gate scores keyword coverage, source diversity and claim count — and labels weak answers THIN.

Verity 0.1.0 — built 12 Nov 2026 for the Geek Room Global AI Hackathon 2026 (Tavily track). Extractive synthesis: every claim is a sentence from a retrieved source; nothing is generated. Provider: …. No account, no tracking, no data stored.

Honest limits: answers are only as good as the retrieved sources; Wikipedia is an encyclopaedia, not a primary source; a GROUNDED verdict means the claims are cited, not that they are true. Always open the source before you quote it.
