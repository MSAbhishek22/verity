The solution

Don’t trust the answer.
Audit it in one glance.

1

Search live

Tavily web search when a key is set; the free Wikipedia API otherwise. Both run in parallel — best result wins.

2

Quote, don’t invent

Extractive synthesis: the answer is built only from retrieved sentences. No LLM, no generated claims.

3

Gate the answer

Every claim keeps its citation. A verification gate scores groundedness 0–100 and stamps the verdict.

Plus an evidence constellation — sources as nodes in a rotatable 3D space around the question, so the shape of the evidence is visible at a glance.

How it works

Three honest steps, no black box.

Step 1

Retrieve

Keyword search over Tavily + Wikipedia in parallel (9 s budget). Sources keep their ranking.

Step 2

Extract

Sentences scored by question-keyword overlap, de-duplicated, capped at 6 claims. Each keeps its source.

Step 3

Gate

Score + verdict from the audit trail. Weak evidence gets a THIN stamp, not a confident paragraph.

score = 50% keyword coverage + 30% source diversity + 20% claim density

Verdicts: GROUNDED ≥ 70 · PARTIAL 40–69 · THIN < 40 · NO EVIDENCE 0
